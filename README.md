# 💰 Трекер доходов и расходов

Одностраничное веб-приложение для учёта личных финансов. Без сборки и зависимостей — всего три файла: `index.html`, `main.css`, `script.js`.

## Возможности

- **Дэшборд** — доходы, расходы и баланс за период (месяц, прошлый месяц, год, всё время), графики:
  доходы и расходы по месяцам, объёмная кольцевая диаграмма расходов по категориям, динамика баланса.
- **Аналитика** — норма сбережений, расход в день, прогноз на текущий месяц, финансовая подушка,
  правило 50/30/20, сравнение категорий со средним и персональные рекомендации.
- **Операции** — добавление, редактирование и удаление (CRUD), фильтры, поиск и сортировка.
- **Категории** — свои категории доходов и расходов с цветами.
- **Настройки** — валюта (по умолчанию узбекский сум; также USD, EUR, RUB, KZT), экспорт и импорт данных в JSON.
- Дизайн в стиле glassmorphism, светлая и тёмная тема, адаптивная вёрстка, плавные переходы между вкладками.

## Запуск

Откройте `index.html` в браузере. Для графиков нужен интернет — библиотека [Chart.js](https://www.chartjs.org/) подключается с CDN.

## Хранение данных

Все данные хранятся локально в браузере (`localStorage`) и никуда не отправляются.
Чтобы перенести данные на другое устройство, используйте экспорт и импорт JSON в настройках.
