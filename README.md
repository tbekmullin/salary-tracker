# 💰 Трекер доходов и расходов

Веб-приложение для учёта личных финансов с аккаунтами и облачным хранением.

**Трекер:** https://salary-tracker-vert-kappa.vercel.app
**Лендинг:** https://salary-tracker-landing.vercel.app

Фронтенд — три файла без сборки (`index.html`, `main.css`, `script.js`), сервер — функции Vercel в папке `api/`, данные — PostgreSQL в [Neon](https://neon.tech).

## Возможности

- **Дэшборд** — доходы, расходы и баланс за период (месяц, прошлый месяц, год, всё время), графики:
  доходы и расходы по месяцам, объёмная кольцевая диаграмма расходов по категориям, динамика баланса.
- **Аналитика** — норма сбережений, расход в день, прогноз на текущий месяц, финансовая подушка,
  правило 50/30/20, сравнение категорий со средним и персональные рекомендации.
- **Кредитные карты** — лимит, задолженность и доступный остаток по каждой карте, загрузка лимита,
  напоминание о дне платежа, погашения, история и график трат по картам.
  Расход можно оплатить картой; погашение уменьшает долг, но не считается расходом.
- **Аккаунт** — регистрация и вход по email и паролю, синхронизация между устройствами,
  перенос данных из браузера при первом входе, удаление аккаунта.
- **Операции** — добавление, редактирование и удаление (CRUD), фильтры по категории и способу оплаты, поиск и сортировка.
- **Категории** — свои категории доходов и расходов с цветами.
- **Настройки** — валюта (по умолчанию узбекский сум; также USD, EUR, RUB, KZT), экспорт и импорт данных в JSON.
- Дизайн в стиле glassmorphism, светлая и тёмная тема, адаптивная вёрстка, плавные переходы между вкладками.

## Архитектура

```
index.html, main.css, script.js   фронтенд (статические файлы на Vercel)
api/auth/register.js               POST   регистрация
api/auth/login.js                  POST   вход (не больше 10 ошибок за 15 минут)
api/auth/logout.js                 POST   выход
api/auth/me.js                     GET    текущий пользователь, DELETE — удаление аккаунта
api/data.js                        GET/PUT данные трекера пользователя
api/_lib/core.js                   база, хеширование паролей, сессии, защита запросов
db/schema.sql, db/migrate.mjs      схема базы и скрипт её применения
```

- Пароли хранятся в виде хеша **scrypt**; сессия — случайный токен в cookie `HttpOnly; Secure; SameSite=Lax`,
  в базе лежит только его SHA-256.
- Данные пользователя — один JSON-документ (`user_data.data`) с номером версии: если данные изменились
  на другом устройстве, сервер вернёт 409 и актуальную версию, и ничего не затрётся молча.
- Изменяющие запросы принимаются только со своего домена и только в JSON; на сайт выставлены CSP и другие защитные заголовки.

## Лендинг

Отдельная страница-презентация в папке `landing/`: React + TypeScript на Vite,
[shadcn/ui](https://ui.shadcn.com) (кнопки, карточки, вкладки, аккордеон), Tailwind CSS 4
и [motion](https://motion.dev) (бывший framer-motion) для анимаций и параллакса при прокрутке.
Выкладывается отдельным проектом Vercel `salary-tracker-landing` (Root Directory — `landing`).

```bash
cd landing
nvm use            # Node 22
npm install
npm run dev        # http://localhost:5173
npm run build
```

Анимации учитывают системную настройку «уменьшить движение».

## Локальный запуск

Нужны Node.js 22, [Vercel CLI](https://vercel.com/docs/cli) и доступ к проекту на Vercel.

```bash
npm install
vercel link                      # привязать папку к проекту Vercel
vercel env pull .env.local       # скачать DATABASE_URL
npm run db:migrate               # создать таблицы (повторный запуск безопасен)
vercel dev                       # http://localhost:3000
```

## Выкладка

```bash
vercel deploy --prod
```

После подключения репозитория к Vercel (Project → Settings → Git) каждый `git push` в `main` выкладывается автоматически.
